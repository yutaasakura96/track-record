# The first real import is Attested by an agent's default, and is re-reviewed before M3

The 2026-09-04 import promoted all 112 candidates to Attested in one pass, reasoning that a
self-authored case study asserts its own claims. That reasoning holds, and the grade is still an
agent's default rather than the author's judgement. The facts stay Attested. Re-reviewing them is a
gate before M3 retires the old workflow.

## Why not demote them now

Demoting to Candidate would put 112 review cards in front of any M2 work that needs the data, and those
facts will be touched again anyway when employer linkage lands. The rows stay identifiable by their
import, so a later re-review can be scoped to exactly them.

## Why this is worth recording

The record currently asserts a Provenance the author has not personally given. That is the one place
where this project's premise and its convenience pull apart, and it should not be discovered by someone
reading the import code and assuming a human graded 112 facts that day.
